# Adaptive Media support

Adaptive Media is active development software. The standalone repository has not yet published a replacement for the historical prerelease hosted in the former shared repository.

## Report a problem

Use a GitHub issue for reproducible playback, packaging, settings, or compatibility problems.

Include only what is relevant:

- commit or build tested
- Windows version
- GPU and driver details when relevant
- source container and codec information for media-specific problems
- observed behaviour
- expected behaviour
- the smallest useful log or diagnostic excerpt

For playback issues, note whether the same problem occurs with the repository's reference mpv path when that comparison is available.

## Privacy

Do not upload copyrighted source media, private files, credentials, tokens, personal paths, or unrelated machine information.

For security or privacy problems, use [SECURITY.md](SECURITY.md) instead of a public issue.

## Current support

The repository currently targets Windows 11. Other operating systems and broader hardware combinations are not advertised as supported until they have tested installation and playback paths.

The project does not promise playback of DRM-protected media or every codec, container, driver, and display combination. A useful report identifies the exact input and playback path that failed.
