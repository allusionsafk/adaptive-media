# Historical transport

`legacy/0.3.x/` preserves the text-safe source transport, patch stack,
reconstruction tooling, release notes, and hardware-certification material used
for Adaptive Media 0.3.x in the original shared repository.

These files are historical inputs, not the active application source or release
workflow. They retain their original repository assumptions where required for
historical accuracy. Active development uses the repository-root `src/`,
`tests/`, `installer/`, `payload/`, and `scripts/` directories.
